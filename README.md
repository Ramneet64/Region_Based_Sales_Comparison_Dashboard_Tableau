# Region_Based_Sales_Comparison_Dashboard_Tableau
Provide clear visibility into sales performance by comparing selected regions through interactive dashboards.
Tools & Technology: Tableau (Hierarchy, Parameters, Calculated Fields), Data Visualization
Process:
 Created workbook hierarchies for structured, drill-down sales analysis.
 Used parameters and calculated fields to enable dynamic comparisons and flexible filtering across regions.
 Designed an interactive dashboard to visualize multiple sales metrics simultaneously.
Result: Improved business decision-making by giving management real-time insights into regional sales performance and trends.
